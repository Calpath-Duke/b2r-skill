# 按需科研素材：来源与适用方式

核对日期 2026-10-10。资源只在能改善当前结构准确性或制作效率时取用，不先搭图库，不批量镜像网站。AI 插画仍是默认主路径；现成图标可作原样插入、可许可的改编，或必要的图像参考。图像参考也记录来源，不抹去许可义务。

| 来源 | 适合 B2R 的取用方式 | 必须核对 |
|---|---|---|
| [Bioicons](https://github.com/duerrsimon/bioicons) | 少量 SVG 器材、分子/细胞符号；直接叠加或作轮廓参考 | 图标各自许可，不能套用网站代码 MIT；优先 CC0，CC BY 保留作者/链接/改动，CC BY-SA 另确认适用范围 |
| [NIH BioArt Source](https://bioart.niaid.nih.gov/) | 专业解剖、细胞与实验器材插画，按条目选择所需格式 | 具体条目的 Public Domain / CC BY 等标识；保存条目 ID、署名、版本/日期，不能泛化到 NIH 全站图片 |
| [Servier Medical Art](https://smart.servier.com/) | 官网按需取得 PNG/PPTX 后插入或改编 | 当前医学图片 CC BY 4.0；保留署名、许可链接、改动。网站页面/标识/数据库不在图片许可内；不建独立再分发图库，不自动抓取 Site Content |

官网依据：
- Bioicons README 要求逐个图标引用作者和对应许可证。本轮固定查看 commit `d29e766ea7580b8063c4f47b29e872db40a4d979`，不是承诺以后所有新增图标相同。
- NIH [FAQ](https://bioart.niaid.nih.gov/faqs) 与 [条款](https://bioart.niaid.nih.gov/terms) 允许教育、科研和商业用途，要求逐条核对署名。Public Domain 条目推荐引用；有署名许可的条目按许可执行。未把其“专业制作”自述当成 B2R 科学复核。
- Servier [使用说明](https://smart.servier.com/using-smart-images-what-you-can-do/) 和 [条款](https://smart.servier.com/terms-of-use/) 区分图片 CC BY 4.0 与网站内容；官网当前提供 PNG/PPTX，不能承诺官方 SVG。Bioicons 中旧 Servier 条目可能为 CC BY 3.0，应保留实际取得版本的许可，不自行重贴新许可。

操作：搜索明确对象 → 打开该条目/固定版本 → 核对许可与作者 → 取得所需单个原文件 → 查看实际内容 → 保存台账 → 用于图件 → 核对改编后的科学含义。来源不清就换明确许可的素材或自行生成，不填“已授权”占位。

宿主将真实下载文件与已核对记录交给：
```sh
python "<SKILL_DIR>/scripts/b2r.py" asset --file "真实素材.svg" --record "已核对许可.json" --out "任务/素材记录"
```
脚本不搜索/下载、不验证权利人的身份；它保存字节/哈希/署名并拒绝缺失许可依据。记录字段见 `asset_ledger.py` 的 validate_record；宿主代填，用户不编辑 JSON。许可状态不能由目录名独自替代对实际来源的判断。

署名放入用户可带走的图注或附带 ATTRIBUTION.md；需要随图传播时，附图注或小型署名，不只藏在开发日志。改编后说明改过颜色、布局或作为生成参考。CC BY-SA 是否影响具体组合/改编应在选用前明确，不能自动改成 B2R MIT。

**BioRender：不抓取、不打包、不重新分发专有素材。** 也不把第三方库的许可解释为模型服务的训练许可或期刊接受 AI 图像的保证。本版无训练行为。

## 轻量 Scientific Reference Kit 决策

参考素材不是每次生成的必选项。先确认当前工具接受参考图，明确本次缺口是结构、轮廓还是风格；再选择一两项有明确作用且许可已核对的素材。实际打开素材，必要时合法转换为工具可读格式；保留原文件、条目链接、许可、哈希和改动。不要用某图的专业外观替代对应机制证据。

0.3.5 在 2026-10-11 重新读取上述三方官网条款/说明，继续保留按条目许可规则。当前宿主可引用本地图片，但尚无同条件测试证明引入这三方素材能提高本次质量，因此本版不新增素材文件或运行依赖，也不宣称 Reference Kit 已验证增益。候选条目下一步应针对具体结构失败做一次有/无参考的受控比较，再决定是否纳入；不预先批量下载。

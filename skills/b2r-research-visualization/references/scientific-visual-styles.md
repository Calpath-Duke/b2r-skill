# Scientific Visual Styles

风格服务于科学信息。三种模式使用同一生成、查看和修改流程；用户也可要求水彩、手绘、线稿等其他合理表现，不硬套标签。

## 决策

**未指定就用 Scientific 2D**。新建插画默认 Classic / Refined 两个独立方案；单图、特定风格、修改与真实数据任务按用户意图执行。两者是同一 2D 模式的视觉变体，不分别拆解科学内容。未指定图件语言用英文，沟通仍默认中文。

| 表达 | 何时使用 | 具体视觉方向 |
|---|---|---|
| Scientific 2D · Classic（A） | 默认方案之一；仅传统二维/Classic；只画一张但未选风格；论文/综述/开题常用 | 期刊综述式科学示意图：白底；全图统一深灰描边、单色平涂；4—5 种克制语义色加灰，颜色固定表示对象类别；膜为简单双线，蛋白为扁平圆角轮廓，细胞为轮廓线并只保留机制需要的细胞器；模块靠留白、细分隔线或极浅底色区分。无渐变、高光、纹理、投影、发光和透视。 |
| Scientific 2D · Refined（B） | 默认方案之二；仅 Refined / Soft-depth 2D；汇报、图形摘要、展示 | 精致二维生物医学插画：与 A 相同的对象、关系、位置与标签；形内柔和双色明暗与渐变、细致脂双层、所需细胞器、轻微叠放层次，并给组织/胞外空间加淡色语境背景。光照均匀、深度克制；箭头与 T 形端仍是清晰平面矢量线。不用高光球、写实/三维渲染或厚重阴影。 |
| Scientific 2.5D | 用户明确要求体积/立体/写实，或关键科学表达确实依赖深度 | 统一视角、柔和光照、适度体积与纹理；结构细节有材料依据，给标签和关系留净空。 |
| Hybrid Scientific | 二维信息结构与特定局部深度各有明确沟通用途 | 明确立体区域，其余箭头/文字/统计二维组织；一致的色板、抽象程度和细节密度。不是复杂机制图的兜底。 |

“有细胞器/膜/神经元”本身不足以触发 2.5D。需要深度时用一句理由说明其沟通作用；仅“用于 PPT”不改变默认。用户明确风格优先，改变宿主或语言模型不改变科学内容与默认风格。

## 共享的专业表达

主标题 → 模块标题 → 科学说明 → 数值/图例，层级稳定；同类标签对齐、换行和间距一致。用形态、线条、配色共同编码科学对象，保持同图细胞、器官与图标的抽象程度协调。精确信息可用独立文字/箭头层，准确性优先但不以几何替代主体插画。

Classic 与 Refined 共用对象、科学关系、分区、标签和颜色含义；允许协调间距，不能增加机制或靠换色伪造差异。Refined 的细节必须来自已规划对象，而非添加新的受体/细胞器。

| 维度 | A · Classic | B · Refined |
|---|---|---|
| 背景与分区 | 白底；留白、细线或极浅底色模块 | 淡色组织/胞外语境（血管壁、内皮衬里、模块底色） |
| 对象 | 科学符号：扁平轮廓 + 单色平涂 | 同一符号的插画化：形内明暗、膜细节、细胞器 |
| 线条与文字 | 统一描边；细连线、实心小箭头、T 形端 | 同样的平面矢量连线与标签，叠于插画之上 |
| 适用 | 论文正文图、综述机制图、技术路线 | 汇报、图形摘要、展示首图 |

Classic 避免两种失败：一是“精美插画化”（立体纹理、球状蛋白、高光、渐变），二是“PPT 化”（同质厚卡片 + 剪贴画图标 + 文字堆叠）。期刊示意图的专业感来自：每个对象是有科学含义的符号（受体跨膜、复合物拼接、探针标记小分子、质谱峰、转录箭头），层级清楚的模块标题，括号/梳状线表达归属，以及少量一致的连接符号。

实测（2026-10-12，同一宿主生图工具）：Classic 风格段写成具体的描边、填充和背景约束后，前后对照中纹理、高光、球状蛋白和虚构化学结构基本消失；Refined 在同一请求正文下获得明显不同的语境表现。但 Refined 的插画细节会占用模型对关系的表达能力，其关系错误多于 Classic，必须单独看图核对，不能因 Classic 通过就默认通过。Publication-oriented 是设计取向，不表示期刊许可。概念蛋白体积不是 PDB 结构；真实结构、化学键连和定量图需对应来源及工具。

## 传入工具与修改

不只记录风格名字：请求中明确当前需要的轮廓、平涂/体积、色板、标签层级与阅读顺序，避免同时要求平面和电影级写实材质。简单图只需一句视觉要求；复杂图也不堆砌形容词。Brief 已记录过的信息不用再建 visual_intent 副本，旧记录仍兼容。

| 自然语言反馈 | 优先操作 |
|---|---|
| 喜欢第一张/使用B/改第二张 | 按实际展示顺序映射 Classic/Refined 文件；继承该图及共同 Brief，只修改所选版本 |
| Classic布局、Refined质感 | 用 Classic 的已确认布局与 Refined 的描边/明暗处理组合；不重做科学规划 |
| 改成二维/减少立体效果 | 引用当前图，改轮廓/材质/明暗，保留对象、关系和内容；整体转换会重绘，不承诺像素锁定 |
| 统一医学图标 | 以现有主导的描边、明暗和细节为准，处理不一致区域 |
| 提高文字可读性/调整间距 | 优先改独立字号、换行、对齐及连接端点，不重生成主体 |
| 精简论文风格 | 减少装饰，统一层级；保留必要标签、科学关系和假设说明 |

检查合并到正常交付查看：2D 是否仍以平面形态为主，2.5D 是否保留需要的空间层次，混合区域是否协调。仅发现具体问题才修，不另开风格评分循环。
